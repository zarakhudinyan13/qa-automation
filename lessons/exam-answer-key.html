Part B

import { allSettledOrThrow } from './promises.js';

export async function closeBoth(contextA, contextB) {
  await allSettledOrThrow([
    () => contextA.close(),
    () => contextB.close(),
  ]);
}

Full marks only when both closes are tasks passed to allSettledOrThrow and the call is awaited. No marks for Promise.all or for two separate awaits: the first throw would skip the second close.
