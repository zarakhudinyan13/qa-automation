Part B — 5 points

Full marks: both closes are passed to allSettledOrThrow as tasks, and the call is awaited.

import { allSettledOrThrow } from './promises.js';

export async function closeBoth(contextA, contextB) {
  await allSettledOrThrow([
    () => contextA.close(),
    () => contextB.close(),
  ]);
}

2 points if they call allSettledOrThrow but forget await, or pass promises that have already started in a way that still waits for both.

0 points for await contextA.close(); await contextB.close(); or for Promise.all. The first throw skips the second close. Promise.all rejects on the first failure and does not by itself guarantee the caller observes the second close.

Same shape as cleanup() in utils/session.js, which disposes the API context and closes the browser context through allSettledOrThrow.
